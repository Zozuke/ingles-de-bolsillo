Constructor de frases

Así se combinan las piezas: Sujeto + Verbo + Artículo + Sustantivo. Empieza viendo estos ejemplos fijos, y luego usa los menús para armar tus propias oraciones — afirmativas, negativas o preguntas, en presente, pasado o futuro, con o sin adjetivo.

Ejemplo: cambia solo el sustantivo

    Ahora también puedes: negar, preguntar, describir, cambiar de tiempo

      Ahora arma tú la frase

      Nota: aquí usamos do / does / did con todos los verbos (incluido have) para que el patrón de negación y pregunta sea siempre el mismo mientras lo aprendes. Más adelante encontrarás casos especiales como “I haven’t”.

      Más combinaciones con las mismas piezas

      Mismo sujeto, mismo verbo, mismo tiempo y mismo tipo de oración — solo cambia el sustantivo. Así se generan frases nuevas en vez de memorizarlas una por una.

        Hecho para aprender inglés combinando piezas, no memorizando frases sueltas. · El audio usa la voz del propio dispositivo (Web Speech API).
